Product story

Built around one simple workflow

01

Open

The chatbot appears immediately. No large marketing wall blocks the product.

02

Ask

Messages are sent through a secure Netlify Function to Gemini, never exposing the API key in the browser.

03

Continue

Conversation context remains available for follow-up questions, revisions, and long-form thinking.

04

Return

Logged-in users can sync history and preferences through Supabase and continue from any supported device.

Architecture

A simple system with clear boundaries

Each part has one job: the browser handles the interface, Supabase handles identity and saved data, and the backend function protects the Gemini request.

Browser Input, interface, rendering
Netlify Function Validation and secret handling
Gemini AI response generation

Design principles

What guides the product

01

Useful before impressive

The product prioritizes a working conversation over decorative marketing sections.

02

Privacy by structure

Public browser keys remain separate from server-only secrets and user-owned data.

03

Context without clutter

History, settings, and help exist on separate pages so the chat remains visually focused.

04

Comfort across devices

The interface adapts from desktop to mobile without hiding the core input experience.

Security and privacy

Your account data stays scoped to you

Authentication and saved conversations are handled through Supabase. Row Level Security is intended to keep each account restricted to its own profile, messages, conversations, and settings.
